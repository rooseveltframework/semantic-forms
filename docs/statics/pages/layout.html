Responsive columns

This feature makes it so the form fields will grow, shrink, expand the number of columns, or reduce the number of columns based on how much space exists in the container. You can customize it by applying various colspan-# classes to various elements in the form markup structure.

Set number of columns a single input field takes up

You can specify the number of columns an input will span using the colspan-# class on the element. The inputs are responsive and will shrink according to available space. Available numbered classes are colspan-1 through colspan-5:

colspan-full can also be used to force an input to take up the entire width of a form:

Align elements within the responsive grid

Use classes to align an element at the start, center, or end of its available space. Available classes are align-start, align-center, and align-end.

Set which column a single input field goes in

You can place a field in a particular column using the col-# class on the element. Available numbered classes are col-1 through col-5. It can be combined with colspan-#, in which case col-# decides where the field starts and colspan-# decides how wide it is.

Positions are responsive in the same way spans are: when the form narrows to fewer columns than the class asks for, the field falls back to flowing into the next free space rather than forcing a column that is no longer there.

Fields in p tags

Where a is more structure than you need, a field and its label can go in a instead. These do not get the float label treatment, so the label stays beside the field.

Tabs

Add the tabs class to an element holding one per tab. Each fieldset's names its tab.

Semantic Forms builds the tab strip, wires up the tab and tabpanel roles, and moves between tabs with the left and right arrow keys, Home, and End. Left alone the markup is a stack of labelled field groups, which is what a visitor without JavaScript gets, so nothing is hidden from them.
